## Research

<details>
<summary><b>On the Metastability of Bipodal States in Transformer Attention Dynamics</b> &nbsp;·&nbsp; <em>NC State, 2026</em></summary>
<br/>

Supervised by [Dr. Ryan Murray](https://rwmurray.wordpress.ncsu.edu/). Analyzes a phase in transformer attention dynamics where token embeddings split into two antipodal clusters and persist there for exponentially long times before collapsing into a single consensus.

→ [vasumenon.com/projects/metastable-transformer-attention](https://vasumenon.com/projects/metastability-transformer-attention)

<br/>
</details>

<details>
<summary><b>Some Structures in Transformer Architectures</b> &nbsp;·&nbsp; <em>Budapest Semesters in Mathematics, 2025</em></summary>
<br/>

Supervised by [Attila Jung](https://attilajung.github.io/) at ELTE. Expresses the self-attention mechanism as a Kronecker product acting on input embeddings, making the separable structure of attention explicit and providing a framework for interpreting information flow through zero- and one-layer transformers. Written for the [ELTE Advanced Directed Reading Program](https://drp.elte.hu/index.php/adrp-reports/).

→ [Paper (ELTE DRP)](https://drp.elte.hu/wordpress/wp-content/uploads/2026/01/Vasudev_Menon.pdf)

</details>
